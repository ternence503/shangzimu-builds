# Whisper 字幕排版試用版 preview.6

修正小視窗：窄視窗三步上下排列、常駐說明收進「按鈕用途說明」，寬視窗三欄且說明隨寬度換行。最低高度 760，避免內容裁切。字幕面板改為固定比例，暫不提供拖拉分隔線。

操作區分成「① 自動整理 → ② 檢查與修改 → ③ 完成與儲存」。按鈕下有用途說明。「匯出給剪輯軟體（SRT）」產生剪輯用字幕；「儲存進度，下次繼續」保存可重新編輯的 JSON，兩者用途不同。

改善詞組保護、自然語句分塊與短尾行問題，新增所選字幕實際換行預覽。匯入含細部時間的 JSON 原稿／專案，按「套用排版」後另存新 SRT，不必重新辨識。

修正 Mac 的 llvmlite／LLVM 安裝失敗：移除不使用的舊引擎依賴及啟動匯入。請从新解壓資料夾啟動，不必刪舊環境。

完整解壓後，請先閱讀本資料夾「新手指南.txt」，或在程式按「使用說明」。

Mac 雙擊「▶ 啟動 Whisper.command」；Windows 雙擊「▶ 啟動 Whisper.bat」。首次準備需網路及安裝權限；影音與字幕在本機處理。

選檔轉錄 → 整理字幕 → 保存 JSON 專案 → 另存 SRT → 到剪輯工具預覽。可先按「先試範例」練習。

本包專注講座／影片字幕；雲端文字轉語音及歌詞分離暫停用。正式版資料夾未修改；試用環境、模型與 Windows 捷徑分開，Mac 系統工具仍使用 Homebrew。

尚未完成乾淨安裝、Windows實機、真實音訊及剪輯工具匯入驗證，不宣稱零協助驗收通過。
