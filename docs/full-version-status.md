# 全功能版驗收狀態（2026-09-14）

要求：四頁功能、五種語音模型、實際安裝並正常開啟，以及 Git 原始碼與可下載成品。舊 1.4.1 Release 不是全功能版。

## 已驗證

- 原始碼環境：五模型英文與中文合成語音轉錄、細部時間。
- 非敏感合成文字：12 種雲端音色、1040 字分四段合成及影音工具解碼。
- 官方 UMX-HQ 固定權重：SHA-256 校驗、本機語音分離產出。
- 115 項單元測試與 6 項 Windows 可攜封裝契約測試通過；不是 Windows 原生安裝驗收。
- 獨立 QA 指出切模型記憶體累積、停止時非同步例外風險；已改為單模型快取、協作式停止及安全回滾，並補回歸測試。
- 人聲分離執行檔封裝完成，36 秒自製語音＋伴奏混音處理兩個分塊並完整產出；不代表真實歌唱辨識準確度。
- 第一輪封裝 App 系統禁網驗收發現介面將 Path 物件直接交給只接受字串的引擎；已修正並補回歸測試，正在重封裝重測，不能沿用失敗前的來源引擎試驗宣稱介面成功。
