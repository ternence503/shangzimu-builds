# 全功能版驗收狀態（2026-09-15）

要求：四頁功能、五種語音模型、實際安裝並正常開啟，以及 Git 原始碼與可下載成品。舊 1.4.1 Release 不是全功能版。

## 已驗證

- 原始碼環境：五模型英文與中文合成語音轉錄、細部時間。
- 非敏感合成文字：12 種雲端音色、1040 字分四段合成及影音工具解碼。
- 官方 UMX-HQ 固定權重：SHA-256 校驗、本機語音分離產出。
- 新加保存文字空白正規化回歸後，118 項單元測試通過；先前 6 項 Windows 可攜封裝契約測試通過。不是 Windows 原生安裝驗收。
- 獨立 QA 指出切模型記憶體累積、停止時非同步例外風險；已改為單模型快取、協作式停止及安全回滾，並補回歸測試。
- 人聲分離執行檔封裝完成，36 秒自製語音＋伴奏混音處理兩個分塊並完整產出；不代表真實歌唱辨識準確度。
- 封裝 App 系統禁網驗收已通過五種模型的實際 GUI 轉錄與細部時間，且切換模型僅保留一個引擎。最初 Path 型別錯誤及分離子程序的資源入口已修正。
- 同一禁網驗收已成功產出歌詞 TXT／LRC／SRT。字幕專案比對因文件契約會去除文字頭尾空白而失敗，驗收改為比對正規化結果，並加驗原始細部時間及設定；新版整條驗收待重跑，不能標為整體成功。
- 封裝 App 的 1035 字非敏感合成文字分四段配音、合併及解碼通過。
- 人聲分離移除不使用的 SoX／GPL 解碼依賴，改用 Apple 系統 C++ runtime；自行編譯 LLVM OpenMP 18.1.8，保留完整來源與授權，替換後實際 frozen 分離成功。仍需整包依賴閉包與完整驗收。
- GitHub run 34862640528：兩種 Mac 基本封裝、安裝與離線轉錄成功；Windows 在兩項 Mac 專用符號連結測試失敗，已限制測試平台，原生 Windows 須重新建置。此 run 尚未包含新的 LLVM 替換及完整五模型驗收，不可沿用為新版整體證明。

## 隱私與授權
